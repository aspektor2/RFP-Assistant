# RFP Response Assistant

An AI-powered web app that helps a sales team respond to RFPs. Upload an RFP PDF and the app extracts the questions, drafts answers grounded in a company knowledge base using the Claude API, assigns confidence levels, flags items needing human review, and exports a completed DOCX response package.

Built as a portfolio project demonstrating AI document processing, knowledge-grounded generation, structured outputs, and human-in-the-loop workflows — all in a single dependency-free HTML file.

## Features

- **PDF upload** with drag-and-drop and line-aware text extraction (pdf.js)
- **AI question extraction** that handles both question-style ("What is your...?") and directive-style ("Please describe...") RFPs, with a heuristic fallback parser when the API is unavailable
- **Knowledge-grounded answers** generated by Claude from `company-profile.txt` (embedded), with High / Medium / Low confidence levels
- **Review notes** flagging answers that need human verification (missing certifications, pricing, assumptions)
- **DOCX export** generated entirely client-side (Office Open XML via JSZip)
- **Sample RFP included** for one-click demos

## How it works

1. pdf.js extracts text from the uploaded PDF, preserving line structure
2. Claude identifies the questions/requirements (one API call)
3. Claude answers them in batches of 4, grounded strictly in the embedded knowledge base, returning structured JSON with `{question, answer, confidence, reviewNote}`
4. The UI shows metrics, previews, and review flags; export builds a real .docx in the browser

If the API is unreachable at any step, a built-in parser and placeholder answers keep the workflow demonstrable, with a banner explaining what happened.
